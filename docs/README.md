# docs — the paper trail

- `JUDGE-SCRIPT.md` — the two-minute guided demonstration:
  every step, with the expected output of every step, run
  before it was written down.
- `BRAIN-WRAPPER-SPEC.md` — the heartbeat and liveliness
  measurement spec: what the probes ask, what the profile
  records.
- `gate0-seller-verification.md` — Gate 0: how a seller's
  measured record becomes a profile and a verdict, and the
  evaluation that reproduces the separation.
- `gate4-confusion-matrix.md` — the delivery gate's v1
  matrix (12/20). **History, not the current gate.**
- `gate4-confusion-matrix-v2.md` — the v2 matrix (18/20):
  mask-measured colour and form, the two named divergences,
  and the calibrated-band limit of the colour claim.
- `sam-3.1-call-shape.md` — the hosted SAM 3.1 request and
  response shape the delivery gate is built against.
- `machine-layer.vtt` — the demo film's machine-readable
  layer: briefings for reviewing agents, timed to the film's
  scenes, including the legislation gap list. It is written
  for machines; that it is not addressed to human readers is
  the design, not an omission.

Trap: if the v1 and v2 Gate 4 documents disagree, v2 is the
gate that ships; v1 is kept so the failure stays on record.
