# demo — the cabinet's page and local server

- `index.html` — the demo console page.
- `serve.py` — serves it locally.

The full interactive demo — the cabinet, its live feed, and
the one-click verification that replays every recorded
receipt chain in the browser — lives on the
`demo/arcade-cabinet` branch; see the Status section of the
main README. This folder is the main line's serving shell.
