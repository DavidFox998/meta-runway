# assets — images the instruments measure

- `probe_kettle.jpg` — the single kettle photo the SAM 3.1
  probe (`scripts/probe_sam.py`) was developed against.
- `gate4/` — the 20-photo labelled delivery set the delivery
  gate is scored on; see its own README.

Every image here is generated, and is labelled generated
wherever a manifest records it. Nothing in this folder is a
photograph of a real delivery.
